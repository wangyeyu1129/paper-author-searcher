# 逐论文作者证据：真实 API 检索对比

比较对象为用户已有的 `hinton_papers.reviewed.json` 与新获取的 `hinton_papers.authorship.json`。沿用归档中 resolved 身份的已确认 Author ID，不按姓名搜索论文，不改动旧文件。详细证据和逐来源统计见 [JSON 对比报告](paper_authorship_comparison.json)。这不是人工 Ground Truth 评估。

| 指标 | 原归档 | 原数据使用新规则离线分析 | 新 API 数据与新规则 |
| --- | ---: | ---: | ---: |
| 原始来源记录 | 890 | 890 | 890 |
| 去重条目 | 656 | 656 | 573 |
| verified | 130 | 126 | 341 |
| needs_review | 526 | 530 | 232 |
| rejected 条目 | 0 | 0 | 0 |

新检索的 OpenAlex 428 条、Semantic Scholar 462 条均完成 5 页分页；没有解析失败或作者详情扩展错误。没有可用的已确认 DBLP Author ID，该来源未查询，所以整体 `complete=false`。不能将这些数量称为教授全部发表数量。

新旧来源记录的 source / paper ID / author ID 三元组全部一一对应，没有新增或删除原始记录。890 条新记录都有作者详情和外部 ID，且 API 作者列表中均观察到查询目标 ID。这个观察仅证明数据库中的关联声明，仍可能继承来源的作者消歧错误。API 未提供的 ORCID、机构等字段继续为空。

新数据包含 428 条 OpenAlex 论文的原始署名；相对于旧数据，215 条作者字符串列表发生变化，题名、年份、DOI 和 venue 未变。新模型同时保留解析后的姓名、原始署名及实际机构，并在合并后保留来源限定的作者详情和稳定标识符。

变化原因：

- 仅运行新规则就将旧数据中 4 个 verified 条目降为待审核，涉及论文集、Peer Review 或其他非标准来源分类。它们仍在归档中。新增保护没有为了数量增长放宽姓名阈值。
- 新 verified 条目中，167 个有明确目标 ID、兼容署名及论文机构一致的证据，262 个有稳定论文身份和跨来源逐论文目标 ID 的证据，55 个仍有有限的已验证共同作者辅助证据。这些类别重叠，不应相加；本次没有依靠 ORCID 一致性取得 verified 的条目。
- 两条 OpenAlex 来源记录的原始署名中间名缩写与确认身份冲突，而解析后的姓名仍一致；这说明仅看解析后姓名和 Author ID 会隐藏冲突。来源记录标为 rejected，合并条目保留为 needs_review，供人工检查原文署名、录入错误或身份误关联。
- 通用的“姓氏, 名字缩写”格式被用于比较，原始署名保留；缩写仍不足以单独确认身份。没有针对教授或论文添加特例。
- 同一批新元数据仅移除 `external_ids` 后的诊断得到 660 个组，保留外部 ID 则为 573 个组。稳定标识符提供了旧归档缺失的重复连接；没有降低标题、年份或作者去重阈值。这一诊断并不证明所有新合并都正确，仍需人工同一出版物标注评估。

验收依据包括证据完整保存、来源 ID 保留、可见冲突进入审核、异常列表不能靠共同作者重合提升状态，以及原始记录均可追溯。verified 数量增加本身不构成 Precision 或 Recall 提高的证明；后续应使用独立人工 Ground Truth 运行 Evaluation。

Python 3.8.0 下 156 项单元测试通过，涵盖缺失/错误作者 ID、原始署名冲突、截断列表与扩展失败、大作者列表、非标准类型、跨来源 ID 与 ORCID 冲突、合并保存及旧身份刷新门控。未实现 PDF 下载。

# 召回率修复：逐项离线验证（2026-10-19）

依据召回率诊断报告中的修复清单，按推荐顺序逐项实现。每项都在 `calibrated-with_hints-20261018` 上用 `paper-benchmark run --replay-from` 离线重放后再做下一项。

离线重放的含义：
- 元数据请求只从 HTTP 缓存读取，其他网络请求一律拒绝；
- 锚点使用原 run 保存下来的结果；
- 整个过程 API 花费为 0。

当前代码的基线重放（`replay-0-baseline`）与原 run 相比，32 人中 30 人完全一致，其余 2 人各差 1 篇。

## 与诊断预测不同的地方

- **修复 2 需要额外处理一个问题。** OpenAlex 按 Wei Wang 的 ORCID 查询时，返回了一个自身记录着另一个 ORCID 的同名档案 A5100391888，导致整组被判为"ORCID 冲突"。现在，记录自身的 ORCID 与提供的 ORCID 不一致时，就不再把它当作锚定记录。
- **修复 4 需要加一道保护。** Wei Lu 带 ORCID 的 OpenAlex 档案混入了多位同名者，挂了 89 个机构，曾使 17 篇明显不是他的论文（印染、纳米孔 DNA、核辐射成像）被判为已确认。现在机构历史超过 `maximum_history_institutions`（12）的身份不提供历史机构证据。加上这道保护后，Wei Lu 没有新增误检，Lu Lu 新增的 6 篇未标注论文都是他本人的。
- **修复 5 暴露了一条真值重复。** Kevin Ellis 真值里同一论文的 ICML 版和 arXiv 版是两条记录，已合并为一条。

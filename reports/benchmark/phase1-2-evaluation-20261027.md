# Phase 1 / Phase 2 评测（2026-10-27）

评测对象：锁定身份（输入格式、身份发现、发表列表提取、ORCID 作品列表）与多源检索（新数据源、DBLP dump、书目库、拆分档案合并、逐篇反查），即 PR #6–#19。评测由助手代为完成，未做人工评测。

数据集 `stratified_researchers_v1`，32 人，1,009 篇真值论文；模式 `metadata`。真值由 AI 助手审阅，**不是人工认证**，因此 gate 的结论最多是 `not_certifiable`。

## 结论

- **最少输入**（只给姓名 + 学校）：宏平均召回 67.2% → **73.2%**，身份解析率 75.0% → **81.2%**，身份精度保持 **100%**，论文精度 99.4% → 99.5%。仍未达到 80% 的门槛：失败的 stratum 检查由 18 项减到 14 项，主要差距在常见中文姓名（51.4%）。
- **带线索输入**（主页、ORCID 等）：宏平均召回 **92.7%**（此前最好为 92.5%），身份精度 **100%**，论文精度 99.3%，**55 项 stratum 检查全部通过**。唯一未通过的是 "真值未经人工审阅"。
- 全量运行暴露了三个回归，均已修复并实测：
  - PR #17：损坏的 CV PDF 使整个身份解析失败；OpenAlex 的聚类 ORCID 否决本人论文锚点。
  - PR #18：同名者因共享 DOI 被并入已由 ORCID 确认的分组。
  - PR #19：缩写署名（"A. Kundaje"）被当作不兼容姓名，使 DBLP 记录加入后 Semantic Scholar 档案被挡在分组外。

## 局限与说明

- **真值由 AI 审阅**，未经人工认证；本发表列表作为身份证据时，"逐篇反查找到本人列出的论文" 在一定程度上是自证的，精度仍由逐篇归属验证把关。
- **未实测的部分**（缺少密钥）：LLM 发表列表提取（`ANTHROPIC_API_KEY`）、网页搜索（Brave / Tavily / Exa）、CORE、OpenReview。它们有单元测试和离线夹具，但没有在线结果。默认也没有配置任何 OAI-PMH 机构知识库。
- **最少输入下的 Huan Zhang**：没有主页时，他的 OpenAlex ORCID 聚类是同名者混合体，按姓名 + 学校无法区分，仍只有 2/67。
- **Semantic Scholar 限流**：没有 API key 时 429 很常见，单次运行的结果可能有几篇的波动。
- 每次在线运行都受各来源当时状态影响；`--replay-from` 可离线重放已缓存的运行。

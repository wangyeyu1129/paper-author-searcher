# 同校同名误收：ORCID 锚定的作者 ID 也要核对院系（2026-10-30）

数据集 `stratified_researchers_v1`。真值由 AI 审阅，未经人工认证。

## 问题

PR #35 之后，最少输入的 Yang Liu（清华计算机系）误收了 2 篇论文，作者匹配精度从 100% 降到 96.9%：
- 一篇生物电子学论文，署名单位是电子工程系；
- 一篇人因工程论文，署名单位是工业工程系。

原因：
1. DBLP 主页发现给出了 Yang Liu 的 ORCID，他的 OpenAlex 作者 ID（A5086000078）因此有了 ORCID 锚点。
2. 有 ORCID 锚点的作者 ID 原本完全免于常见姓名精度检查，包括论文署名的院系核对。
3. 但数据库里的 ORCID 属于整个作者聚类（`orcid_scope: resolved_author`），不是论文本身的证据。OpenAlex 把清华的同名作者的论文也归进了这个聚类。
4. 于是"作者 ID + 署名 + 学校都是清华"就把这两篇验证成本人的了。

## 改动

- 豁免拆成两层：
  - ORCID 锚定的作者 ID 仍然不会被整体判为"外来片段"（`exempt_anchor_kinds` 不变）；
  - 但其中每篇论文都要过院系核对：署名写的是本人院系以外的单位时，不能只凭学校通过验证。
- 新配置 `PrecisionGuardConfig.unit_exempt_anchor_kinds`，默认为空。设为 `('orcid',)` 即恢复原行为。
- 不写单位的署名仍然中立。本人自己论文上出现过的单位（`home_department_share`）照常算作本人单位。
- 其他验证途径不受影响：论文级 ORCID、本人主页列出的论文、DBLP 认证档案。

## 方法

离线回放（不联网，确定性）。同样的录制输入，分别用 `main` 和本改动各跑一次：

| 输入 | 人数 |
|---|---:|
| `current-minimal-20261027`（最少输入） | 32 |
| `final-hints-20261027`（带提示） | 32 |
| `p3-min`（最少输入，含 DBLP 主页发现） | 4 |
| `p3-hint`（带提示，含主页原文） | 9 |

## 结果：按真值

| 输入 | 已验证的真值论文（对照 → 改动） | 误收（对照 → 改动） |
|---|---|---|
| 全 32 人最少输入 | 894 → 894 | 4 → 4 |
| 全 32 人带提示 | 939 → 939 | 4 → 4 |
| `p3-min` | 208 → 208 | **2 → 0** |
| `p3-hint` | 206 → 206 | 1 → 1 |

- 召回没有变化。
- Yang Liu 的作者匹配精度回到 100%。
- 身份精度 100% 不变。

## 结果：真值之外

真值只是抽样，所以我还核对了所有因本改动不再"已验证"的论文（一共 72 篇，没有新增的）。

**同名者的论文，去掉是对的（约 67 篇）：**
- **Wei Lu（密歇根，电子与计算机系）**：52 篇。署名都是机械工程系，是密歇根另一位研究力学和电池的 Wei Lu。真值抽样里没有这些论文，所以以前没被发现。
- **Yang Liu**：12 篇。单位是水利、工业工程、电子工程、车辆与运载学院等。
- **Wei Wang（UCLA）**：2 篇。单位是中科院自动化所、机械与航空航天系。
- **Jia Liu**：1 篇。单位是广州国家实验室。

**可能是本人的早期论文，被误伤（约 5 篇）：**
- **Jia Liu**：3 篇（2012–2017）。他读博和做博后时在哈佛化学系 Lieber 组。
- **Sindy Tang**：1 篇（2006）。她读博时在哈佛化学系。
- **Yang Liu**：1 篇，《Deep Learning in Machine Translation》。署名单位被解析成"自动化所"。

这些都是本人换过院系、而旧单位在本人自己的论文里占比太低（不到 `home_department_share`），所以没被认作本人单位。这几篇仍保留在结果里，状态是"待审"，没有被丢掉。

## 取舍

- 以约 5 篇早期论文转为待审，换来去掉约 67 篇同名者的论文；按真值计，召回不变、精度上升。
- 要找回早期论文，可以加一条规则：本人主页或 CV 上的教育/任职经历里出现过的院系，算作本人单位。这需要先能解析出经历，留作后续。

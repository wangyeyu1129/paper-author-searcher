# 合规要点与待确认事项

这份文档说明服务实际做了什么、有哪些法律风险，以及上线前需要你决定什么。它不是法律意见。正式对外提供服务或大规模发送邮件之前，请让律师按你的公司所在地和收件人所在地审阅。

## 服务实际做了什么

| 行为 | 现状 |
|---|---|
| 查询学术数据源 | 使用 OpenAlex、Semantic Scholar、DBLP、Crossref、arXiv、ORCID 等的公开接口，受各自的使用条款约束 |
| 抓取网页 | 读取搜到的研究者主页和出版方页面。User-Agent 是 `paper-author-searcher/0.1`。**不检查 `robots.txt`** |
| 下载和保存 PDF | `mode=full` 时把校验过的公开 PDF 存到本地卷或对象存储，凭 API 密钥可以下载 |
| 保存个人信息 | 姓名、学校、院系、ORCID、调用方提交的邮箱和主页，以及论文作者名单 |
| 保留期限 | 已结束的搜索和文件默认 30 天，HTTP 缓存（含抓取的网页）默认 90 天，备份默认 14 份（每天一份） |
| 删除 | 只有到期自动删除。**没有按请求删除某一条搜索或某一个人的接口** |
| 第三方传输 | 姓名和学校会发送给网页搜索服务（Tavily 等）和各数据源；开启 Claude 提取时，页面内容会发送给 Anthropic（默认关闭） |

## 需要你决定的三件事

### 1. PDF 怎么处理

"开放获取"不等于"允许再分发"。很多作者主页上的 PDF 只是可以公开访问，没有授权别人复制和再次提供。

| 选项 | 做法 | 风险 |
|---|---|---|
| **只给链接（推荐）** | 调用方用 `mode=pdf-urls`，服务不保存文件，只返回校验过的公开链接 | 最低；原文件消失后链接会失效 |
| 只供内部读取 | 调用方用 `mode=full`，只让冷邮件 agent 读取，文件不发给任何外部的人，到期删除 | 中等；仍然存在复制行为 |
| 向外分发 | 把 PDF 提供给第三方 | 最高；需要逐篇确认许可证，不建议 |

### 2. 是否遵守 `robots.txt`

现在不检查。美国和欧盟对抓取公开网页的法律判断不一，但违反 `robots.txt` 或网站条款会提高风险，也可能被封 IP。

推荐上线前加上检查：`robots.txt` 禁止的页面不读取。代价是部分主页和全文读不到，影响需要实测后才知道。

### 3. 冷邮件的法律依据

这部分责任主要在冷邮件 agent 一侧，但这个服务提供了它的输入。

| 地区 | 要点 |
|---|---|
| 美国（CAN-SPAM） | 主题不得误导，写明真实发件人和地址，提供退订并在 10 个工作日内处理 |
| 欧盟、英国（GDPR、PECR） | 处理个人信息需要合法依据（通常主张"正当利益"，要做并保存评估）；要告知信息来源，响应访问和删除请求；部分国家发送营销邮件需要事先同意 |
| 中国（个人信息保护法） | 处理公开的个人信息需在合理范围内；个人明确拒绝的不得处理；向境外提供有额外要求 |
| 加拿大（CASL） | 商业邮件通常需要同意；公开发布的工作邮箱有有限例外，邮件内容要与其职务相关 |

研究者的姓名和工作单位是公开信息，但这不代表可以不受限制地处理，GDPR 和个人信息保护法对公开信息同样适用。

## 推荐的上线默认值

如果你没有其他要求，建议这样开始：

1. Agent 调用时使用 `mode=pdf-urls`，不保存 PDF。
2. 缩短保留期：`RETENTION_DAYS=30` 保持不变，`HTTP_CACHE_RETENTION_DAYS` 从 90 改为 30。
3. 由 agent 维护退订名单，提交搜索前先查这个名单。
4. 记录你的合法依据和删除请求的处理流程。

## 还没有实现的

下面两项需要写代码，要等你决定后才做：

- 遵守 `robots.txt`。
- `DELETE /v1/searches/{id}`，以及按研究者删除（要同时清理文件、HTTP 缓存，并说明备份何时过期）。

在此之前，收到删除请求只能手动处理，或者等保留期到期。备份里的数据最多再保留 14 天。
